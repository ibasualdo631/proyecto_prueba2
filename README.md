## Descripción del Proyecto
Implementación del sistema bancario y gestión de cuentas en Java, aplicando diseño orientado a objetos.

## Estructura del Repositorio
* `src/`: Código fuente del proyecto (`.java`).
* `docs/`: Diagramas UML, modelos de objetos y documentación de análisis del sistema.
* `.gitignore`: Configuración para excluir binarios `.class` y carpetas de configuración local.
